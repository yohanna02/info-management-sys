# CE Department — Student Records (mobile)

React Native (Expo SDK 57, Expo Router) app for the Computer Engineering
department student records. Same Convex backend, same data, same features as
the web app in the parent folder, with a mobile-native UI.

## Features

- Admin sign in / create account (Convex Auth, email + password).
- Dashboard: total students, per-level and per-status counts, recent students.
- Students list: debounced search across name, matric number, email, and
  program, level and status filters, infinite scroll pagination.
- Student form: create and edit with passport photo from the photo library
  (uploaded to Convex storage on save), native date picker for date of birth,
  the same validation rules and messages as the web form.
- Student detail: all record fields, edit, delete with confirmation.
- Sign out from the tab header.

## Setup

The Convex backend lives in `../convex` and is shared with the web app. Start
the Convex dev server from the repository root, then start Expo:

```bash
# terminal 1 (repository root)
npx convex dev

# terminal 2
cd mobile
npm install
npx expo start
```

`mobile/.env.local` must contain `EXPO_PUBLIC_CONVEX_URL` pointing at the same
deployment as the web app's `VITE_CONVEX_URL`. If it is missing, the app shows
a setup message instead of starting.

Press `a` for an Android emulator, `i` for an iOS simulator, or scan the QR
code with Expo Go. All native modules used here (image picker, date picker,
storage) are included in Expo Go.

## Scripts

| Script               | What it does                                    |
| -------------------- | ----------------------------------------------- |
| `npm start`          | Start the Expo dev server                       |
| `npm run android`    | Start and open on an Android emulator           |
| `npm run ios`        | Start and open on an iOS simulator              |
| `npm run typecheck`  | Type-check with the project TypeScript config   |
| `npm run lint`       | Run ESLint (`eslint-config-expo`)               |
| `npm run export`     | Bundle the app for all platforms (bundle check) |

## Layout

```
index.js          Expo entry: URL/FormData polyfills, then expo-router/entry
metro.config.js  Metro config (watchFolders for the shared ../convex folder)
src/
  app/            Routes only (Expo Router file-based routing)
    _layout.tsx        Convex client + auth provider + root stack
    login.tsx          Sign in / create account
    (tabs)/            Dashboard and Students tabs (auth-gated)
    student/           new, [id], [id]/edit
    +not-found.tsx
  screens/        Screen bodies rendered by the route files
  components/     Reusable UI (button, fields, cards, rows, …)
  utils/          Student types/helpers, photo picking and upload
  theme.ts        Colours, spacing, typography ported from the web app
  constants.ts    App name, default program, entry-year floor
```

The Convex API is imported as `@convex/_generated/api`, a tsconfig path alias
pointing at `../convex/_generated`. `metro.config.js` adds the repository root
to `watchFolders` so Metro can read those generated files, and pins `convex` to
this project's copy.

## Notes

- `index.js` replaces the default `expo-router/entry` entry so that
  `react-native-url-polyfill` is loaded before the Convex client module.
- Convex Auth needs an explicit `storage` prop in React Native because its
  default is `window.localStorage`. `src/utils/auth-storage.ts` wraps
  AsyncStorage, which ships in Expo Go, so the session survives an app restart.
  The Convex docs recommend `expo-secure-store` for production, but that needs
  a development build, so swap the adapter if the app is EAS-only.
- `expo-env.d.ts` is generated by Expo but is committed here so typed routes
  resolve before the first `npx expo start`.
